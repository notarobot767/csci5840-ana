TSS is an 359TTSB initiative to provide tactical node monitoring and other capabilities to the theater and brigades through an assortment of web applications hosted on a tactical node in the rear connected via GAIT PoP. All of the applications are free and or open source and can be accessed via tactical or strategic networks. For NIPR, this would also include Azure Virtual Desktop (AVD).

The primary user applications are:

Zabbix : An active probing software that can interact with nodes or via ICMP, SNMP, DNS, NTP, HTTP, etc. This is similar to SNMPC and solarwinds except that it can store any metric and visually display said data in a number of widgets. This is useful for capturing latency and being able to show: when a node was last online, when an outage occurred, when a node conducts a change in transport, etc.

Kibana : Kibana is a log visualization tool that is a part of an ecosystem of applications created by Elastic and others that ship, transform, and ingest data. Primary meant for log visualizations, we can also use it to analyze bandwidth utilization from nodes by ingesting NetFlow. This will tell us over a given period of time, how much a node downloads/uploads data, when data is most consumed, and what users/IPs are responsible. We can also use this to analyzse system logs form network devices or security agents installed on user laptops.

Files : Using a NGINX web server with the Fancy Index module, this is a basic file server. Perhaps more useful on enclaves other than NIPR, this server would enable sharing and distribution of file without a secret or other token smart card.

Cisco Meeting Server : This is a collaboration suite that users can join via web client or VoIP end device. It enables voice, video, screen sharing, IM chat that users can join in an ad hoc manner. This is useful for classified domains where not all participants have a secret token. Furthermore, as this service is hosted at the tactical edge, this reduces latency, making it a ideal candidate for an exercise communication platform.
